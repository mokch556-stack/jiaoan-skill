# 教案生成 Skill（jiaoan-skill）v2.3.1

> 2026-09-10 发布 v2.3.1 · 由《人工智能通识》教案 v4.13 + 第2次课教案修订稿（v1.5 终版）全部修改要求系统化沉淀

## 这是什么

一个能**一次性输出达到学校教案质量标准**的教案生成技能包。输入开课说明三级矩阵 + 本次课课点，输出完整教案 docx（表头 9 行教案表 + 教学过程 + 课堂训练/课后作业/教学后记 + 板书）。

## 能保证的质量

- ✅ 内容与开课说明三级矩阵 KSA **完全对齐**（★☆级别一致，矩阵没有的不写入表格）
- ✅ **课后作业与矩阵"学习产出及测量标准"逐条匹配**——每条产出① ② ③ 各有 1 个可提交/可测量落点（课堂书面化或巩固作业），无"只讲不交"的产出（v2.1.0）
- ✅ 212 汇报规范（每节课抽签随机不少于 1 组、2+1+2 分钟、展示 10 分/点评 8 分给分要点）
- ✅ 前测高阶任务、后测开放题、任务具体可执行
- ✅ 课程思政近 2 年权威新闻 + 截图 + 网址 + 融入方式 + 达成态度目标
- ✅ 学校模板格式：9 行教案表、4 列板书、宋体小四、固定 22 磅行距（含表格内文字）、图片段单倍行距居中、步骤标题加粗、首行缩进 2 字符、正文竖版/板书横版、无封面无批注
- ✅ 12 项校验清单全过才交付

## 怎么用

对我说"生成第X次课教案"或"重做教案"，并给出：
1. 开课说明（含三级矩阵）
2. 本次课包含哪些课点
3. （可选）格式基底教案

我会按 SKILL.md 的流程自动完成：读矩阵 → 复制模板基底 → 填充表头/教学过程/作业/板书 → 格式处理 → 校验 → 打开 + 通知。

## 包内资源

| 资源 | 说明 |
|------|------|
| `templates/教案模板基底_齐工程教2023-11号.docx` | 学校官方模板格式基底（表0九行教案表/分节符/字体/行距/板书4列），新教案=复制基底+文字填充，格式自动继承 |
| `scripts/dump_full.py` | 导出全部段落+表格文本（残留/一致性检查） |
| `scripts/verify_format.py` | 通用格式校验：表格结构/行距/字体残留/封面批注/新老文本 |
